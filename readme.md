\# Simple Thumbs Up Counter



A lightweight, beginner-friendly UI component built with plain HTML, CSS, and vanilla JavaScript. 



\## 🚀 Features

\* \*\*Interactive Counter:\*\* Click to increment, click again to decrement.

\* \*\*Visual States:\*\* Smooth CSS transitions for hover and active (liked) states.

\* \*\*Clean Architecture:\*\* Standard separation of concerns (HTML, CSS, and JS files).



\## 📁 File Structure

```text

├── index.html   # Markup structure

├── style.css    # Layout \& button styling

└── script.js    # Click handler \& state logic

```



\## 🛠️ How to Run

1\. Download or clone this folder.

2\. Double-click `index.html` to open it instantly in any modern web browser.
